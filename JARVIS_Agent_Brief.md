**1. Контекст проекта**

**1.1 Что такое JARVIS**

JARVIS --- полностью локальный голосовой ассистент на Python для
Windows. Работает на ноутбуке с видеокартой RTX 3050 Laptop (4 ГБ VRAM).
Основной язык общения --- русский. ИИ-мозг подключён через OpenRouter
API (внешний запрос). Всё остальное --- локально.

Главный цикл работы:

1.  Пользователь произносит «Hey Jarvis»

2.  JARVIS воспроизводит сигнал Beep

3.  Записывает голос (VAD --- автостоп по тишине)

4.  Переводит в текст (faster-whisper, GPU)

5.  Отправляет текст в LLM через OpenRouter

6.  Получает ответ и озвучивает (Silero TTS)

**2. Архитектура агента**

**2.1 Ключевая идея: Tool Calling**

Сейчас brain.py всегда возвращает текст. Нужно добавить режим, в котором
LLM возвращает JSON с вызовом инструмента. Это стандартный паттерн «tool
calling» / «function calling».

Как это работает:

7.  Пользователь говорит: «Найди мне ноутбук из вотсапа»

8.  brain.py отправляет в LLM запрос + список доступных инструментов

9.  LLM возвращает JSON: {\"tool\": \"search\", \"query\": \"ноутбук HP
    цена купить\"}

10. Tool Dispatcher перехватывает JSON, вызывает нужный инструмент

11. Инструмент возвращает результат (текст, список, данные)

12. Результат снова отправляется в LLM для формулировки ответа

13. JARVIS озвучивает итоговый ответ

**2.2 Формат Tool Calling**

LLM должен уметь возвращать JSON в следующем формате:

> {
>
> \"action\": \"tool_call\",
>
> \"tool\": \"search\",
>
> \"params\": {
>
> \"query\": \"ноутбук HP Pavilion цена 2024\"
>
> }
>
> }

Или для текстового ответа --- обычный текст без JSON. Dispatcher
определяет тип ответа по наличию поля \"action\": \"tool_call\".

**2.3 Системный промпт для агентского режима**

Добавить в brain.py к существующему системному промпту следующий блок:

+-----------------------------------------------------------------------+
| **СИСТЕМНЫЙ ПРОМПТ --- АГЕНТСКИЙ БЛОК (добавить в brain.py)**         |
|                                                                       |
| Ты --- JARVIS, голосовой ИИ-ассистент. Ты умеешь не только отвечать,  |
| но и выполнять задачи на компьютере пользователя. Когда задача        |
| требует действия (найти информацию, открыть файл, запустить           |
| программу, управлять системой) --- вызывай инструменты. Отвечай на    |
| русском языке. Для вызова инструмента верни ТОЛЬКО валидный JSON без  |
| пояснений. Для обычного ответа --- верни только текст без JSON.       |
+-----------------------------------------------------------------------+

**5. Технические ограничения**

**5.1 Железо**

-   GPU: RTX 3050 Laptop, 4 ГБ VRAM --- не загружать дополнительные
    модели на GPU

-   Whisper turbo занимает \~1.5 ГБ VRAM --- остаток \~2.5 ГБ

-   Не использовать local LLM (ollama и т.п.) --- весь LLM через
    OpenRouter API

-   ОС: Windows 11
